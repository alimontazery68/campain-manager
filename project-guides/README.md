# بسته راهنمای کمپین‌ها — نسخه ۱.۰

این پوشه را در پروژه نگه دارید. فایل JSON مرجع داده و Markdownها نسخه خواندنی همان راهنماها هستند. برای اصلاحات بعدی یکی را مرجع اصلی قرار دهید و دیگری را از آن تولید کنید.

هفت شناسه با مدل‌های فعلی پروژه هماهنگ‌اند. فایل‌های اصلی آموزشی و نام مدرس‌ها در این پوشه نیستند.

برای UI فقط فیلدهای آموزشی را ارسال کنید؛ agent و قواعد داخلی سمت سرور بمانند.

تعریف روش‌ها پشتوانه منبع دارد؛ ترتیب‌بندی اجرایی، سنجه‌ها و قواعد اعتبارسنجی جمع‌بندی و طراحی محصول است. سند خصوصی منشأ همراه پروژه منتشر نشود.

آزمون مهم: راهنما پیشنهاد است و خودبه‌خود اثبات نمی‌کند که خروجی مدل همه مراحل را رعایت کرده است. خروجی طرح نیز باید اعتبارسنجی شود.
