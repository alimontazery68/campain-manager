# کمپین‌منیجر

نسخه محلی فارسی برای مدیریت کمپین کانال ایتا با Next.js، NestJS، TypeScript، Prisma و PostgreSQL. Docker لازم نیست. ورود کاربران بنا به درخواست شما فعلاً خارج از محدوده است؛ این نسخه را عمومی منتشر نکنید.

## اجرای محلی

PostgreSQL فعال باشد و مشخصات واقعی اتصال در `apps/api/.env` تنظیم شده باشد. فایل موجود را با نمونه جایگزین نکنید. کلید DeepSeek فقط در بک‌اند است.

```powershell
npm install
npm install --prefix apps/web
npm install --prefix apps/api
npm --prefix apps/api run prisma:generate
cd apps/api
npx prisma migrate deploy
cd ../..
npm run dev
```

فرانت: http://localhost:3000 — سلامت API: http://localhost:4000/health
پورت‌ها با WEB_PORT و API_PORT در فایل محیطی قابل تغییرند. پس از تغییر محیط، پروژه را دوباره اجرا کنید. راهنمای PostgreSQL: [LOCAL-SETUP.md](LOCAL-SETUP.md).

## جریان کار

حذف تأییدشده، ویرایش و درخواست طرح تازه: [CAMPAIGN-MANAGEMENT.md](CAMPAIGN-MANAGEMENT.md). بازطراحی کمپین اجراشده به‌صورت نسخه تازه انجام می‌شود تا تاریخچه قبلی محفوظ بماند.

ثبت اطلاعات فقط پیش‌نویس ایجاد می‌کند. ساخت طرح با درخواست صریح AI انجام می‌شود؛ بعد از بررسی و تأیید، آماده‌سازی و روزهای اجرا ساخته می‌شوند. برنامه عمومی تکراری قبل از تأیید نمایش داده نمی‌شود.

- فرم سریع یا دقیق، پیشنهاد واقعی، تاریخ شروع، تردیدها، شواهد، قالب‌ها و ظرفیت روزانه.
- کمک اختیاری AI برای اطلاعات نامعلوم؛ پذیرش پیشنهادها جداگانه است.
- ویرایش اطلاعات و طرح پیش‌نویس، مأموریت‌ها، کارها، CTA و جزئیات محتوا.
- افزودن، جابه‌جایی، بایگانی، قفل، رد یا بازگرداندن کار؛ وابستگی شناسه‌ای آماده‌سازی.
- تولید و ساخت مجدد محتوا؛ کوتاه‌تر، صمیمی‌تر و اقدام روشن‌تر با دستور تخصصی.
- نتایج روزانه، سرنخ گرم، بازخورد و یادداشت؛ خالی نامعلوم است، نه صفر.
- تحلیل محدود به داده‌های ثبت‌شده؛ اصلاح روزهای آینده فقط بعد از تأیید مستقل.
- پایان، جمع‌بندی، آموخته دستی یا پیشنهاد AI با شواهد و سطح اطمینان؛ انتقال فقط اختیاری.
- تاریخچه تغییرات و دریافت گزارش JSON بدون درخواست AI.

کارهای انجام‌شده، قفل‌شده و محتوای ذخیره‌شده در اصلاح AI محافظت می‌شوند. بایگانی، حذف دائمی نیست. ذخیره همزمان با نسخه قدیمی رد می‌شود؛ دوباره‌فرستادن همان درخواست ثبت، کمپین تکراری ایجاد نمی‌کند.

## هزینه AI

بررسی جدید کمپین، واقعیت/سیگنال/فرضیه را جدا می‌کند و اصلاح جزئی کار آینده فقط با تأیید مستقل انجام می‌شود؛ راهنمای قرارداد، mock و محدودیت مالکیت: [OPTIMIZATION.md](OPTIMIZATION.md).

فقط دکمه‌های کمک، ساخت طرح، تولید/بازنویسی محتوا، بررسی وضعیت و پیشنهاد آموخته‌ها ممکن است درخواست هزینه‌دار بفرستند. مشاهده، ذخیره دستی، کپی، تأیید، ثبت نتیجه، پایان و گزارش‌گیری AI ندارند. خروجی تحلیل و آموخته با داده یکسان از حافظه خوانده می‌شود.

متن مطابق کد: [SYSTEM-PROMPTS.md](SYSTEM-PROMPTS.md). چاپ مجدد پس از build:
`node scripts/print-ai-prompts.cjs`

## بررسی کیفیت

```powershell
npm run lint
npm run typecheck
npm test
npm run build:api
npm run test:integration
npm run test:e2e
npm run build:web
```

تست یکپارچه به PostgreSQL محلی و تست مرورگر به فرانت و API فعال نیاز دارد. مرورگر Chrome نصب‌شده استفاده می‌شود. تست‌ها کمپین‌های خودشان را پاک می‌کنند؛ داده شما را هدف نمی‌گیرند. پاسخ AI در تست‌ها کنترل‌شده است و هزینه ندارد؛ صحت راهبرد و ادعاهای خروجی واقعی مدل هنوز نیازمند ارزیابی کاربر است.

برای build فرانت، اجرای dev را متوقف کنید تا خروجی .next همزمان تغییر نکند.

## معماری و امنیت

بک‌اند مسئول اعتبارسنجی Zod، ذخیره Prisma، اتصال AI، کنترل نسخه و تراکنش‌های تغییر برنامه است. فرانت رابط RTL و پیش‌نویس محلی را نگه می‌دارد و از مسیر /api به بک‌اند متصل می‌شود. برنامه‌ریزی، محتوا، تحلیل، یادگیری، نتایج و کنترل کارها سرویس‌های جدا دارند.

API_HOST و WEB_HOST پیش‌فرض 127.0.0.1 هستند. CORS محدود و درخواست‌های AI محدودسازی زمانی دارند؛ این‌ها جایگزین احراز هویت نیستند. جزئیات انتشار آینده و پشتیبان‌گیری در [DEPLOYMENT.md](DEPLOYMENT.md) و وضعیت واقعی در [REMAINING-WORK.md](REMAINING-WORK.md).
